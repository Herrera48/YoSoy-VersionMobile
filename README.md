# YoSoy Mobile

## Descripción

YoSoy es una plataforma de telemedicina enfocada en salud mental. Esta
aplicación móvil está orientada al perfil **paciente**, y busca resolver la
dificultad de acceder de forma simple y ordenada a la atención en salud
mental: encontrar profesionales adecuados, gestionar turnos sin fricción y
mantener un registro personal del propio estado de ánimo a lo largo del
tiempo.

Proyecto académico desarrollado para la materia **Laboratorio de Programación
II**, con metodología ABP (Aprendizaje Basado en Proyectos): la aplicación se
construye de forma incremental, unidad por unidad, a lo largo de la cursada.

## Cómo levantar el proyecto

### Requisitos previos

- [Node.js](https://nodejs.org/) (LTS)
- [Expo Go](https://expo.dev/go) instalado en tu celular (Android o iOS), o
  un emulador configurado

### Instalación

```bash
git clone https://github.com/Herrera48/YoSoy-Mobile.git
cd YoSoy-Mobile
npm install
```

### Ejecución

```bash
npm run start
```

Esto abre Expo Dev Tools. Desde ahí podés:

- Escanear el código QR con la app **Expo Go** en tu celular
- Presionar `a` para abrir en un emulador de Android
- Presionar `i` para abrir en un simulador de iOS (requiere macOS)
- Presionar `w` para abrir la versión web
